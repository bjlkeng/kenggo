## Review-driven fixes

The first independent review found four failure/integrity defects. Invalid
agent metadata could prevent a forfeit from being saved; agent initialization
exceptions lost responsibility; replay trusted contradictory behavior flags
and missing observation rows; and its empirical referee was not bound to the
scheduled pin. Each defect has a failing-before regression and a passing fix.

The saved-result loader now checks decision/pass coverage and snapshots,
ending evidence, fault responsibility and derived behavior flags. It rechecks
known exact pass verdicts and requires independently pinned evidence for known
empirical pass verdicts. Returned records also use the same JSON types as their
saved files, including empirical gain arrays.

The four actual weak games preceded these fixes. Their original source patch
and costs remain pinned. All four archived records also passed the strengthened
replay checks, using an additional 4.182228333 CPU seconds and 4.182383612
elapsed seconds. This was verification of retained evidence; no games were
replaced or rerun. The learner files and its independently reviewed evidence
were unchanged.

After the repairs, both pinned environments pass the complete **285-test suite
with zero skips**, including the native comparison. The package build and
whitespace/link checks also pass. Resolved and unresolved empirical endings
both retain the scheduled referee pin.

The second independent review verified the first four repairs and found a
partial-write recovery defect. Outputs now become visible under their final
names only after flush/fsync, using publication that cannot replace an existing
file. A regression injects a partial write, verifies that earlier records still
load, and keeps the interrupted slot unresolved. Corrupted published records
continue to fail validation. This repair changes persistence only; the original
four game outcomes remain unchanged.

The third review found that abrupt exits during initialization still bypassed
the earlier exception fix. Attribution now follows the startup phase: a crash
or timeout after the worker's ready handshake belongs to agent initialization;
an earlier process failure remains unattributed infrastructure. Regressions
cover both colors and player roles, abrupt exits, timeouts and failure before
the handshake. The existing experiment/game budget checks keep precedence.

Custom opponent adapters, the full validation panel and learned-policy games
remain subsequent E2 work. Same-winner empirical margin spread is stored with
both scores and an unknown dispute-gate flag; its qualification interpretation
must be frozen before making qualification claims. Unknown judgments are
adverse in candidate reliability bounds.
