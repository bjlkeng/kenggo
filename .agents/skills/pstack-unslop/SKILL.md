# Plain prose

Use familiar words, active verbs, and concrete subjects. Cut generic praise, stock openings, decorative formatting, repeated summaries, and claims that have no evidence. State the result directly instead of contrasting it with an invented alternative.

Use one name for each concept. Define necessary technical terms and retain exact code identifiers. Split dense sentences without dropping the articles and verbs needed to read them naturally. Keep uncertainty when it is real, but remove stacked qualifiers.

Preserve content that helps the reader assess the change: what changed, why, the checks performed, and material limits. Brevity is not a reason to hide failed checks or unresolved findings.
